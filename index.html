Get Running in Minutes

Three steps from clone to your first AI-generated, backtested strategy

1

Install with one command

Clone the repo and run the installer. It provisions the uv and bun toolchains plus the frontend and backend environments (--minimal / --full / --extra).

git clone https://github.com/pengwow/quantcell.git
cd quantcell
bash install.sh   # --minimal / --full / --extra，自动配置 uv + bun
2

Generate and backtest via CLI

Turn a natural-language requirement into a strategy, then run an event-driven backtest with a single command.

quantcell strategy generate --requirement "双均线金叉买入" --name dual_ma
quantcell backtest run --symbols BTCUSDT --timeframes 1h --initial-capital 100000
3

Write strategies in Python

Receive bars in on_bar and return a unified axon_quant Action. The same code runs in backtests and live trading.

from axon_quant import Action, ActionType

class DualMA:
    def __init__(self, fast=10, slow=30):
        self.fast, self.slow = fast, slow
        self.closes = []

    def on_bar(self, bar: dict) -> Action:
        self.closes.append(bar["close"])
        if len(self.closes) < self.slow:
            return Action(ActionType.Hold, 0.0, 0.0, "dual_ma", 0)
        fast_ma = sum(self.closes[-self.fast:]) / self.fast
        slow_ma = sum(self.closes[-self.slow:]) / self.slow
        if fast_ma > slow_ma:
            return Action(ActionType.Buy, 0.8, 0.1, "dual_ma", 0)
        return Action(ActionType.Hold, 0.0, 0.0, "dual_ma", 0)
